# Task 1: Exploring and Visualizing the Iris Dataset

### Objective
Analyze and visualize the Iris dataset to understand data distributions, feature relationships, and potential outliers.

### Key Activities
- Loaded and explored the dataset using Pandas.
- Generated summary statistics using `info()` and `describe()`.
- Created:
  - Scatter Plots
  - Histograms
  - Box Plots

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

# Task 2: Predict Future Stock Prices

### Objective
Predict the next day's stock closing price using historical stock market data.

### Key Activities
- Retrieved stock data from Yahoo Finance using `yfinance`.
- Used features such as:
  - Open
  - High
  - Low
  - Volume
- Trained a machine learning model:
  - Linear Regression / Random Forest
- Visualized Actual vs Predicted Prices.

### Technologies Used
- Python
- Pandas
- NumPy
- yfinance
- Scikit-learn
- Matplotlib

# Task 3: Heart Disease Prediction

### Objective
Develop a machine learning model to predict the risk of heart disease based on patient health data.

### Key Activities
- Cleaned and preprocessed the Heart Disease UCI Dataset.
- Performed Exploratory Data Analysis (EDA).
- Trained a classification model:
  - Logistic Regression / Decision Tree
- Evaluated performance using:
  - Accuracy
  - ROC Curve
  - Confusion Matrix
  - Classification Report

### Streamlit Application
A Streamlit-based web application was developed to provide an interactive interface for heart disease prediction.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
