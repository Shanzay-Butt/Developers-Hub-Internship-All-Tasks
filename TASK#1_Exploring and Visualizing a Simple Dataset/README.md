# Task 1: Exploring and Visualizing the Iris Dataset

## Objective
The objective of this task is to learn how to load, inspect, analyze, and visualize a dataset using Python data science libraries.

## Dataset
This project uses the Iris Dataset, a well-known dataset containing measurements of iris flowers from three different species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

The dataset includes:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Tasks Performed

### Data Loading
- Loaded the Iris dataset using Pandas.
- Displayed the dataset shape.
- Printed column names.
- Displayed the first few rows using `head()`.

### Data Exploration
- Used `info()` to inspect data types and missing values.
- Used `describe()` to generate summary statistics.

### Data Visualization
- Created scatter plots to examine relationships between features.
- Generated histograms to visualize feature distributions.
- Created box plots to identify potential outliers.

## Results
The visualizations helped identify:
- Relationships between petal and sepal measurements.
- Distribution patterns of different features.
- Presence of outliers in the dataset.

## How to Run

1. Install required libraries:
   pip install pandas matplotlib seaborn

2. Run the Python script:
   python task1.py
